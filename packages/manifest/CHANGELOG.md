# @artisanpack-ui/manifest

## 1.0.0

### Major Changes

- [#123](https://github.com/ArtisanPack-UI/design-system/pull/123) [`311eccc`](https://github.com/ArtisanPack-UI/design-system/commit/311eccc871af3f7a81bc7ff282ed82ffed7031ba) Thanks [@ViewFromTheBox](https://github.com/ViewFromTheBox)! - First stable release of the design system packages: the behavior engine, the CSS, the component manifest, the testing kit and the upgrade codemods. They power Livewire UI Components 3.0, `@artisanpack-ui/react` 2.0 and `@artisanpack-ui/vue` 2.0.

### Minor Changes

- [#106](https://github.com/ArtisanPack-UI/design-system/pull/106) [`97c2ee5`](https://github.com/ArtisanPack-UI/design-system/commit/97c2ee5e234726110182496e1b328ed3d164c6f5) Thanks [@ViewFromTheBox](https://github.com/ViewFromTheBox)! - Add Chart, Calendar and the Utility wave ([#63](https://github.com/ArtisanPack-UI/design-system/issues/63) to [#65](https://github.com/ArtisanPack-UI/design-system/issues/65), D-045 to D-055).
  
  - `@artisanpack-ui/manifest` adds 11 manifests with docs examples: Chart, Calendar, Icon, ThemeToggle, ThemePreview, Markdown, Code, Kbd, Swap, Carousel and Clipboard. ThemePreview is Livewire only (D-003, D-055).
  - `@artisanpack-ui/css` ships each of them in `apui.components`, plus the shared `.apui-prose` styles.
  - `@artisanpack-ui/behavior` adds the `data` helpers `chartGeometry` and `attachChartTooltip` (Chart draws its own SVG; no chart library, D-045), `calendarModel` and `calendarGridKeydown`, `renderMarkdown` on `marked` (the same HTML as league/commonmark, D-049), and the Code and Kbd helpers; the copy helper (`createClipboard`) with `useClipboard`; the theme helpers (`applyTheme`, `watchTheme`, `themeScript`, D-054); `registerDirectionalIcons` (D-051); and `perView` and reduced-motion autoplay for the carousel widget (D-053). The Alpine plugin registers `apuiChart`, `apuiCalendar`, `apuiClipboard`, `apuiKbd` and `apuiThemeToggle`. Adds the `contrast` Lucide icon.
  - `@artisanpack-ui/testing` regenerates fixtures for the new manifests.
  - Fixes from review: Chart tooltips are positioned within the chart's `body` part, small values and ticks keep the decimals they need, compact values step up a unit when rounding reaches 1,000 (`999,950` → `1.0M`), and `chartSeries` reads ApexCharts-style points (`{ x, y }`, `[x, y]`) with the new `chartPointLabels`. ArrowUp and ArrowDown stop at the Calendar grid's edge. The carousel's snap points before it measures match `carouselPageCount`. A bound `apuiThemeToggle` applies values set from outside.
  - Fixes from the PR reviews: the chart y axis handles any finite range (clamped to ±1e300, tick step at least 1e-10) and prints values of 1e21 and above in full; impossible calendar times are skipped and `focusCalendarCell` keeps "+N more" focus; `renderMarkdown` bounds untrusted input like commonmark (`MARKDOWN_MAX_NESTING` 100, `MARKDOWN_MAX_DELIMITERS` 500) and raw `<img>` takes only PNG/GIF/JPEG/WebP `data:` URLs; the head snippet and `applyTheme` record `data-theme-choice` (`pageThemeChoice`, `startThemeChoice`); new Alpine `apuiMarkdown`; `apuiClipboard` resets when its value changes and offers a manual-copy field after a failure; Code lines keep newline separators; the carousel's autoplay control comes first in the Tab order.

- [#96](https://github.com/ArtisanPack-UI/design-system/pull/96) [`8ce0456`](https://github.com/ArtisanPack-UI/design-system/commit/8ce04560d217aefe47ffea34a144a0363e8e020d) Thanks [@ViewFromTheBox](https://github.com/ViewFromTheBox)! - Add the component manifest ([#26](https://github.com/ArtisanPack-UI/design-system/issues/26)): a JSON Schema (draft 2020-12) for one component's props, variants, sizes, parts, slots, events, accessibility requirements, tokens and the stacks it ships in (D-003), with a Button sample. Includes a validator with the vocabulary rules, the `apui-manifest validate` and `diff` CLI, a typed loader for test harnesses, a manifest diff with Markdown output for upgrade guides, and a PHP loader over a generated `manifests.php`.

- [#103](https://github.com/ArtisanPack-UI/design-system/pull/103) [`691852c`](https://github.com/ArtisanPack-UI/design-system/commit/691852cbbdccc02faddc26ce6b500156e9b0dfa4) Thanks [@ViewFromTheBox](https://github.com/ViewFromTheBox)! - Add the Form and Navigation waves, the Combobox family, DatePicker and Spotlight ([#53](https://github.com/ArtisanPack-UI/design-system/issues/53) to [#57](https://github.com/ArtisanPack-UI/design-system/issues/57), D-020 to D-028).
  
  - `@artisanpack-ui/manifest` adds 26 manifests with docs examples: Textarea, Password, Pin, Range, Toggle, Fieldset, Form, ValidationSummary, RadioGroup, CheckboxGroup, Rating, ColorPicker, File, Signature, RichTextEditor, CodeEditor, Combobox, DatePicker, Breadcrumbs, Link, Pagination, Steps, Tabs, Menu, Navbar and Spotlight. Select's `options` takes `{ label, options }` groups (D-025).
  - `@artisanpack-ui/css` ships each of them in `apui.components`. Combobox and DatePicker reuse the shared field anatomy in `field.css`.
  - `@artisanpack-ui/behavior` adds the Tabs, DatePicker (with a `time` mode) and ColorPicker widgets on Zag (`@zag-js/tabs`, `@zag-js/date-picker`, `@zag-js/color-picker`), Spotlight on the dialog and combobox machines, and the `form` helpers for Signature, RichTextEditor and CodeEditor. Each has an Alpine component (`apuiTabs`, `apuiDatePicker`, `apuiColorPicker`, `apuiSpotlight`, `apuiSignature`, `apuiRichTextEditor`, `apuiCodeEditor`) and React and Vue hooks where there's a machine. The combobox widget gains chips, create, `max`, loading, debounced remote search, match marks, hidden inputs for `name` and translatable labels; its `control` and `input` parts render as `box` and `control` through the new `repart()`. More Lucide icons for the new components.
  - `@artisanpack-ui/testing`: the Vue host passes a fixture's `value` as `modelValue` when the component declares it; the manifest a11y check reads Chromium's `image` role as `img`; `ManifestParity` knows the new widgets' events (`apuiCombobox`, `apuiSpotlight`, `apuiDatePicker`, `apuiColorPicker`); and the PHP twins test reads the example list instead of the pilot names.
