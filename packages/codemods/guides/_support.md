## How long the old version is supported

The previous major gets **security fixes only for 12 months** after the new one ships. No features or component fixes are backported. Each repository's `SECURITY.md` carries the end date from launch day.

The old and new majors can't be mixed in one app: the new CSS replaces DaisyUI, and the two style the same components differently. Upgrade a whole app at once, on a branch.
