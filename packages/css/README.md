# @artisanpack-ui/css

Plain-CSS component layer for ArtisanPack UI. Tailwind is not required.

> **Not published yet.** This package is a scaffold that only declares the cascade layer order. The markup conventions and components arrive with #21, and the optional Tailwind v4 preset (`@artisanpack-ui/css/tailwind`) with #24. The first release is tracked in #81.

Part of the [ArtisanPack UI Design System](../../README.md).
