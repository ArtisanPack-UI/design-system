## [1.0.0] - November 13, 2026

The first stable release of the design system. It's the shared foundation under Livewire UI Components 3.0, `@artisanpack-ui/react` 2.0 and `@artisanpack-ui/vue` 2.0.

| Package | Version |

### Added
- **Design tokens** (`@artisanpack-ui/tokens` 2.0.0)
  - W3C DTCG source, generated as CSS custom properties, a typed TypeScript map and a PHP array
  - Light, dark and high-contrast themes, and comfortable and compact densities
  - Presets switched with `data-preset` on any element: Ledger, Harbor and a `forest` example brand preset, plus a generator for your own brand presets
  - Figma variables export (`@artisanpack-ui/tokens/figma`) covering presets, themes and densities
- **CSS** (`@artisanpack-ui/css` 1.0.0)
  - Plain CSS in cascade layers, so app CSS always wins without `!important`; no preprocessor and no Tailwind required
  - Component styles for every component, a headless entry (`@artisanpack-ui/css/headless`) without the component layer, and an optional Tailwind v4 preset
  - Right-to-left support through logical properties
- **Behavior engine** (`@artisanpack-ui/behavior` 1.0.0)
  - Zag state machines for interactive widgets (dialogs, menus, comboboxes, tabs and the rest) behind one framework-agnostic adapter interface
  - Floating UI positioning with logical start and end placements
  - Adapters for Alpine (Livewire and Blade, including a classic-script build), React (hooks) and Vue (composables)
- **Component manifest** (`@artisanpack-ui/manifest` 1.0.0)
  - A JSON Schema describing each component's props, variants, sizes, parts, slots, events, accessibility requirements, tokens and stacks
  - A manifest for every component, the contract all three stacks are tested against
- **Testing kit** (`@artisanpack-ui/testing` 1.0.0)
  - Manifest fixtures, cross-stack visual regression, axe accessibility checks and API parity checks for Livewire, React and Vue
- **Upgrade codemods** (`@artisanpack-ui/codemods` 1.0.0)
  - React and Vue codemods, and the rules behind the Blade upgrade command, for moving apps to the design-system majors
  - Generated upgrade guides for Livewire, React and Vue
- **Components**, built in waves and shipped in every stack unless noted
  - Pilots: Button, Input, Select, Checkbox, Card, Dialog, DropdownMenu and Toast
  - Form and Navigation waves, the Combobox family, DatePicker and Spotlight
  - Layout, Feedback and Data Display waves, Tooltip and Table
  - Chart, Calendar and the Utility wave
  - ImageLibrary, StreamableContent and ThemePreview are Livewire-only
- **Composer package** (`artisanpack-ui/design-system`): the PHP side of the manifests, the docs examples and the quality-gate kit (Blade fixture host and parity checks)
- **Documentation**: getting started for each stack, foundations, theming, styling, components, accessibility, the behavior engine, the packages and the upgrade guides

### Changed
